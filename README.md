# GBranding Landing Page

A beautiful, modern landing page for GBranding - a premium branding and design subscription service.

## Features

- 🎨 Modern, responsive design
- ⚡ Built with Next.js 15 and React 19
- 💅 Styled with Tailwind CSS
- 🖼️ Custom Satoshi font family
- 📱 Mobile-friendly navigation
- ✨ Smooth animations and transitions

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/your-username/g-branding-landing.git

# Navigate to the project
cd g-branding-landing

# Install dependencies
yarn install
# or
npm install
```

### Development

```bash
# Start the development server
yarn dev
# or
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the landing page.

### Production Build

```bash
# Build for production
yarn build
# or
npm run build

# Start production server
yarn start
# or
npm start
```

## Project Structure

```
src/
├── app/                    # Next.js App Router pages
│   ├── globals.css         # Global styles
│   ├── HomePage.tsx        # Main landing page component
│   ├── layout.tsx          # Root layout
│   └── page.js             # Entry point
├── assets/                 # SVG icons and images
├── components/             # React components
│   ├── BookCallCard.tsx    # Contact/call-to-action component
│   ├── Header.tsx          # Navigation header
│   ├── HeroSection.tsx     # Hero section
│   └── ...                 # Other section components
├── constants/              # App constants
└── fonts/                  # Custom font files (Satoshi)
```

## Tech Stack

- **Framework**: Next.js 15
- **UI Library**: React 19
- **Styling**: Tailwind CSS
- **Font**: Satoshi (custom)
- **Components**: Headless UI
